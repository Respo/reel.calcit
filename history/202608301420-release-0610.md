# Release 0.6.10 / 发布 0.6.10

## 中文

- 发布 Reel 0.6.10，要求 Calcit CLI/`@calcit/procs` 0.13.64 与 Respo UI 0.7.13。
- 保持 Reel 状态模型、updater 与公共 UI API 不变。
- 为 Recollect/Alerts 后续统一升级 Respo UI 依赖解除 strict version-selection warning。

## English

- Release Reel 0.6.10 with Calcit CLI/`@calcit/procs` 0.13.64 and Respo UI 0.7.13 required.
- Keep the Reel state model, updater, and public UI API unchanged.
- Unblock coherent Respo UI upgrades in Recollect and Alerts without strict version-selection warnings.
