# Release 0.6.20

- Upgrade Reel to the Calcit 0.14.11 toolchain (`@calcit/procs` 0.14.11) and align the provider chain to respo-ui 0.7.20, respo-router 0.8.14, Respo 0.16.97, and js-ffi 0.1.16.
- Replace legacy struct/list method dispatch (`.slice`, `.map`, `.foldl`, `.append`, `.concat`) with typed or `&list:*`/`&map:*` accessors so strict preprocessing no longer rejects originless trait origins.
- Introduce `reel.util/unwrap-option`, `reel.util/update-map-dynamic`, and `reel.util/map-indexed-dynamic` as explicit open-boundary adapters for dynamic Option and collection values.
- Type the remaining dynamic component and atom boundaries (`assert-type … Struct`, `State<Enum, Map>`) so `defcomp` expansion and `reset!` type-check under strict mode.
- Revalidated strict Caps, `--check-only` (zero warnings), tests, native and JS typed behaviour, the type/weak-type/deprecated analyses, JS code generation, and the Vite production build.
