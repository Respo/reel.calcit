# Calcit 0.13.64 and Respo UI 0.7.13 / 升级 Calcit 0.13.64 与 Respo UI 0.7.13

## 中文

- 将 Reel 的 Calcit CLI 与 `@calcit/procs` 同步升级到 0.13.64。
- 将 Respo UI 从 0.7.12 升级到 0.7.13，为上层 Recollect/Alerts 解除 strict dependency version-selection warning。
- 保持 Reel 状态模型、updater 与 UI API 不变，并通过 strict Caps、静态分析、JS codegen 与 Node 24 Vite build 验证。

## English

- Upgrade the Reel Calcit CLI and `@calcit/procs` together to 0.13.64.
- Upgrade Respo UI from 0.7.12 to 0.7.13, unblocking strict dependency alignment for upstream Recollect and Alerts.
- Keep the Reel state model, updater, and UI API unchanged, with strict Caps, static analysis, JS codegen, and Node 24 Vite build coverage.
